### 1. Planning
You describe what you want. **Brainstormer** refines it with **Architect**, a technical validator, into a master plan. Then it breaks the plan into epics and tasks.

### 2. Execution
Coder agents implement the tasks. **Epic Manager** starts them when needed, reviews each result, and approves it or sends it back.

### 3. Code Review
**Code Reviewer** audits the finished work against your architecture standards. Findings become new tasks. For independent reviews from other models, add **Peer Reviewer** agents to the Code Review team: Code Reviewer verifies each of their claims itself. It reviews a small change alone, asks one peer for a medium change, and asks all peers for a risky or large change.
